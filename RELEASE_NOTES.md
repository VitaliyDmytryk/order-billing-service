# Release Notes — v1.1.0

Опис змін у версії **v1.1.0** порівняно з **v1.0.0** у модулі `billing.py`.

## Added
* **Спеціальний тариф для Києва:** додано окрему базову ставку доставки `80.0` для міста `"Kyiv"` у функції `calculate_delivery_cost` (ставка для `"Ivano-Frankivsk"` залишилася `50.0`, для інших міст — `110.0`).
* **Явна передача ставки податку:** додано параметр `tax_rate: float = 0.20` у функцію `process_standard_invoice` для конфігурації ПДВ без побічних ефектів.
* **Спеціалізовані функції обробки рахунків:** додано окремі функції `process_standard_invoice(...)` та `process_tax_exempt_invoice(...)` замість універсальної функції з прапорцем режиму.

## Changed
* **Підвищення тарифу за вагу:** коефіцієнт розрахунку вартості доставки за кілограм ваги у `calculate_delivery_cost` збільшено з `12.0` до `15.0`.
* **Перехід до Data Coupling:** проведено рефакторинг зв'язності коду — ліквідовано *Common*, *Stamp* та *Control Coupling*. Функції розрахунку тепер приймають виключно необхідні примітивні параметри (`city: str`, `weight_kg: float`) замість усього об'єкта `CustomerProfile`.

## Breaking Changes
* **Видалено глобальний стан:** прибрано глобальну змінну `GLOBAL_TAX_RATE`.
* **Видалено `process_invoice` та `mode_flag`:** єдину функцію `process_invoice` із керуючим прапорцем `mode_flag` видалено та розділено на окремі функції обробки рахунків.
* **Змінено сигнатури функцій:** виклики `calculate_delivery_cost` та функцій обробки рахунків більше не приймають екземпляр `CustomerProfile` — необхідно передавати рядок `city` напряму.
